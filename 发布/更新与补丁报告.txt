【2026-09-11】黑客端识别 client-guard（拦截外挂客户端进服）
--------------------------------------------------------
类型     : 新功能
更新文件 : 服务器插件(两版) + 客户端mod —— 三份 jar 全部替换
内容     :
  1. 客户端品牌(brand)检查 —— 对所有玩家生效：
     进服 2 秒后读取客户端品牌，命中黑名单即拦截
     (默认覆盖 LiquidBounce/Wurst/Aristois/RushHack/Vape/Sigma
      等常见外挂端品牌特征)，正常原版/Fabric 客户端不受影响；
     统一发客户端的服可开 whitelist-mode: true 只放行白名单品牌
  2. 违规模组黑名单 —— 配套 mod 升级：
     mod 现在把玩家本机的 Fabric 模组列表随机器码一起上报，
     服务器比对 blocked-mods (默认 meteor-client/liquidbounce/
     wurst/baritone 等)，命中即拦
  3. require-mod 强制安装配套客户端(默认关)：
     开启后没装配套 mod 的玩家进服 8 秒内直接被请出，
     适合"只允许自家客户端进服"的运营模式
  4. 处理动作统一调节 client-guard.action:
     kick=踢出并提醒管理员(默认) / alert=仅提醒管理员 / none
  5. mod 上报协议向后兼容：老服务器插件只读机器码自动忽略新段，
     老 mod 不上报列表服务器自动跳过，混装不报错
服务器要做: 服务器插件和玩家 mod 都换新 jar；config.yml 的
  client-guard 整节与 guard-kick/guard-alert 消息键会在启动时
  自动补全，老 config 不用手改
诚实局限 : 客户端上报的内容理论上可被篡改，②③层是提高门槛
  不是绝对防线；部分外挂端不改品牌，①层拦不住；
  配合反作弊行为检测(anticheat-sync 联动)才是完整纵深

【2026-09-10】反作弊封禁联动 anticheat-sync（对接 Grim 等）
--------------------------------------------------------
类型     : 新功能（同日 11:50 补充 Spartan 预置正则）
更新文件 : 服务器插件(两版)
内容     :
  1. 识别主流反作弊执行的封禁命令，反作弊封谁就自动封谁的机器码：
     开箱即用（已内置识别）：
       - 原版 /ban /pardon
       - LiteBans: ban / tempban / ipban / unban
       - Vulcan:   /vulcan ban
       - Spartan:  /spartan ban / tempban / unban
  2. Grim / Matrix / Intave / NCP 没有固定 ban 命令（处罚命令由
     管理员在它们配置里自定义），写成 ban 类命令即自动联动：
       - Grim punishments.yml: "ban %player% 作弊"
       - Intave thresholds:    "ban {player} ..."
       - 也可直接写 "hwidban ban %player%" 直连封机器码
  3. 解封对称联动: litebans unban / spartan unban 同步解除
     机器码封禁 + 原版封禁
  4. 防误封: only-console 默认 true，只认控制台与管理员执行的
     命令（反作弊自动处罚全走控制台，普通玩家乱敲不会触发）
  5. 处罚写成 kick 不联动（踢出≠封禁，防误伤）
服务器要做: 换服务器插件 jar；在反作弊处罚配置里把处罚写成
  ban 类；注意老 config 的 anticheat-sync 节里新预置正则不会
  自动出现（合并只补缺失键），需手动补 spartan 两行

【2026-09-09】v1.0.0 初始版本（首发）
--------------------------------------------------------
类型     : 首发
内容     :
  - 服务器插件 BlazeHwidBan，双版本线:
      1.21线 (Paper 1.21.x / Java 21)
      mc26线 (Paper 26.x / Java 25)
  - 客户端 mod blazehwid (Fabric): 读玩家电脑真实机器码，
    只传 SHA-256 哈希、原始信息不出玩家电脑
  - 核心机制: 客户端指纹(改客户端设置会变的弱标识，原版玩家也有)
    + 真实机器码(装配套 mod 才有的强标识)
  - 指令(权限 hwidban.admin，默认仅 op；别名 /hban):
      /hwidban ban        封玩家(联动封机器码)
      /hwidban banhwid    直接封一个机器码
      /hwidban unban      解封
      /hwidban tempban    临时封禁
      /hwidban list       封禁列表
      /hwidban check      查玩家机器码档案
      /hwidban alt        同机账号情报
      /hwidban info       插件状态
      /hwidban reload     重载配置
  - 机器码封禁生效时自动踢出在线同机账号
  - 数据本地存 bans.json / profiles.json，异步落盘
